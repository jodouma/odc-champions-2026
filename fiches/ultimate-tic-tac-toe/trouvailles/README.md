# Trouvailles : Ultimate Tic-Tac-Toe

Un fichier par trouvaille, nommé `AAAA-MM-JJ-sujet-court.md` (exemple : `2026-11-28-budget-temps.md`).

- Copie le modèle : [`_modele-trouvaille.md`](../../_modele-trouvaille.md)
- Un fichier chacun : deux personnes n'écrivent jamais dans le même fichier, donc pas de conflit.
- Même trouvaille qu'un autre ? Ajoute une ligne « Confirmé par » dans son fichier au lieu d'en créer un second.
