# ODC Champions 2026 · Leaders Code Squad 🇹🇳

**La base commune des équipes de Leaders University** pour ODC Champions 2026 (Orange Digital Center × CodinGame) : briefing, méthode, fiches par jeu et outils d'entraînement.

> ⚠️ **Ce repo est public.** Le règlement interdit tout partage de code entre équipes. Notre règle ici : **jamais** de code de compétition, ni de prompts utilisés pendant une épreuve, ni de liens de connexion. Uniquement des méthodes, des ressources et des squelettes génériques.

## Les dates (heure de Tunis)

| Date | Quoi | Horaire |
|---|---|---|
| Lun 30 nov | Session d'information officielle (en ligne, en français) | 12h30–13h15 |
| **Jeu 3 déc** | **Qualifications nationales · Bot Programming** | **9h00–16h00** (lien à 8h00) |
| Mer 9 déc | Quarts · Coding Escape, puis demi-finales · Optimization | matin / après-midi |
| Jeu 10 déc | Finale · Bot Programming | 9h00–15h00 |

Une seule équipe par pays passe le 3 décembre.
