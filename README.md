# ODC Champions 2026 · Leaders Code Squad 🇹🇳

Repo d'entraînement des 2 équipes de Leaders University pour **ODC Champions 2026** (Orange Digital Center × CodinGame).

> ⚠️ **Ce repo est public.** Le règlement interdit tout partage de code entre équipes. Notre règle ici : **jamais** de code de compétition, ni de prompts utilisés pendant une épreuve, ni de liens de connexion. Uniquement des méthodes, des ressources et des squelettes génériques.

## Les dates (heure de Tunis)

| Date | Quoi | Horaire |
|---|---|---|
| Lun 30 nov | Session d'information officielle (en ligne, en français) | 12h30–13h15 |
| **Jeu 3 déc** | **Qualifications nationales · Bot Programming** | **9h00–16h00** (lien à 8h00) |
| Mer 9 déc | Quarts · Coding Escape, puis demi-finales · Optimization | matin / après-midi |
| Jeu 10 déc | Finale · Bot Programming | 9h00–15h00 |

Une seule équipe par pays passe le 3 décembre.

## Par où commencer

1. Lis le **[briefing (PDF, 7 pages)](docs/Briefing_ODC_Champions_2026.pdf)**.
2. Lis **[quel langage pour quelle épreuve](docs/langages.md)**.
3. Suis **[le plan d'entraînement individuel](docs/entrainement.md)** : chacun crée son propre bot.
4. Regarde **[comment on utilise l'IA](docs/ia-agent.md)**.
5. Affronte les autres : **[jouer les uns contre les autres](docs/jouer-ensemble.md)** (pseudos, classements, étapes).
6. Comprends **[les ligues et comment monter](docs/ligues.md)**.
7. Pars des squelettes dans [`starters/`](starters/).
8. Fais combattre ton bot contre ceux de l'équipe avec [l'arène locale](arena/).
